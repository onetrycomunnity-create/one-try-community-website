# ONE TRY COMMUNITY — Website

Website landing page responsif untuk HP, tablet, laptop, dan PC.

## Isi paket
- `index.html` — halaman utama
- `styles.css` — desain responsive dark / silver / electric blue
- `script.js` — menu mobile dan tahun copyright
- `one-try-community-logo.webp` — logo resmi merah-silver terbaru dengan copyright

## Cara upload ke GitHub lewat HP
1. Buka repository `one-try-community-website`.
2. Tekan **Add file** → **Upload files**.
3. Ekstrak ZIP ini terlebih dahulu di HP.
4. Upload seluruh isi folder (index.html, styles.css, script.js, README.md, dan folder assets).
5. Tekan **Commit changes**.
6. Buka **Settings** → **Pages**.
7. Pada **Build and deployment**, pilih **Deploy from a branch**.
8. Pilih branch `main`, folder `/ (root)`, lalu **Save**.
9. Tunggu proses deployment selesai. Buka alamat GitHub Pages yang ditampilkan.

## Keamanan admin
Paket ini belum mengaktifkan login admin. Ini disengaja: autentikasi admin tidak aman jika hanya dibuat dengan password yang ditanam di HTML/JavaScript. Untuk dashboard admin sungguhan, hubungkan Supabase Auth, aktifkan Row Level Security (RLS), dan buat policy akses admin di backend. Jangan pernah memasukkan `service_role` key atau password rahasia ke repository publik.
